# Site YK — Personal Portfolio

A personal portfolio website. Includes public pages, a research blog.

## Pages

| Route | Description |
|---|---|
| `/` | Home |
| `/about` | About Me |
| `/projects` | Projects list |
| `/research` | Research posts |
| `/contacts` | Contacts |
| `/admin` | Admin dashboard (login required) |
