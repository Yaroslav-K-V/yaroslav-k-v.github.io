Car Managing Book

Desktop Application for Vehicle Maintenance Tracking

Windows desktop app for managing and analyzing car maintenance history.

Features

  • Full CRUD system for maintenance records
  • Advanced filtering by date, mileage, cost, and service type
  • Cost tracking with aggregated statistics
  • Input validation (email, phone, structured fields)
  • Persistent local storage

Architecture

  • MVVM (Model-View-ViewModel)
  • Repository pattern for data access

Tech stack

C#, .NET, WinForms
