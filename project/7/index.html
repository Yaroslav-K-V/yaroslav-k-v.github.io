Applied Data Science

Exploratory Data Analysis with Python — Jupyter Notebook

Collection of EDA exercises across multiple datasets, focusing on data interpretation and visualization.

Covered analyses

  • London Housing Dataset — price per m² and per room, neighborhood comparison (Kensington vs Chelsea), market segmentation (budget / mid / premium)
  • Retail Business Dataset (10K orders) — revenue, profit margins, ROI, regional performance, customer segmentation, time series trends, payment distribution
  • Computer Science Students Dataset — GPA vs programming skills (Python, SQL, Java), gender-based distribution, domain to career pathway analysis

Visualizations

seaborn, matplotlib heatmaps, distributions, trends. Focus on extracting insights, not just plotting.

Tech stack

Python, pandas, numpy, matplotlib, seaborn
